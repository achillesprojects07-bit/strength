CALM STRENGTH — Elbow-Safe Weight Loss + Injury-Safe Fitness App

HOW TO USE
1. Upload all files to a GitHub repository.
2. Turn on GitHub Pages from Settings > Pages.
3. Use the generated GitHub Pages link on your phone.

FILES
- index.html
- styles.css
- app.js
- manifest.webmanifest

FEATURES INCLUDED
- Today dashboard
- Elbow Green / Yellow / Red / Nerve safety filter
- Daily Calorie Budget based on maintenance, planned workout calories, and target loss per week
- Live food counter and movement counter
- Food logging with common Filipino/real-life food estimates
- Movement logging and walking estimate
- Safe workouts filtered by elbow status
- Progress check-in for weight and waist
- Local phone/browser storage

IMPORTANT NOTE
This app estimates calories and exercise burn. It is not medical advice. If elbow pain worsens, if you have numbness/tingling, or if pain is severe, consult a qualified medical professional or physical therapist.
